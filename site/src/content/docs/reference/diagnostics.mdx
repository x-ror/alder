Every check the language server runs reports its problems under a stable code, which is the name of its rule: `Html/ImgAlt`, `Syntax/Ruby`. In VS Code the code appears next to the message in the Problems panel and in the hover over the underlined text, with `ruby-templates` as the source. The `ruby-templates check` command prints the same messages as `file:line:column: severity: message [Code]`, and exits with 1 when it finds an error or a warning (not for information, such as `Rails/InstanceVariableInPartial`), or a problem in a `.ruby-templates.toml`.

The messages are those of Erubi, Rails, Haml 7, Slim 5, Pug 2 and Prism, or quote the section of the HTML standard that is broken. Each entry below shows a template that triggers the code and the message `ruby-templates check` prints for it, at the same line and column.

## Turning diagnostics off

Turn a check off in the `.ruby-templates.toml` of the project, by the rule's name (the code):

```toml
[Html.ImgAlt]
enabled = false

[Html.DuplicateId]
exclude = ["app/views/legacy/**"]

[Rails.MissingPartial]
exclude = ["**/*.haml"]
```

The file is read by the editor and by `ruby-templates check`, and it beats the settings below: a rule the file switches with `enabled` stays as the file says. The [rules reference](/vscode-ruby-templates/reference/rules/#configuration) describes the file.

Or list the codes to turn off for a language in your `settings.json`:

```json
"rubyTemplates.erb.disabledDiagnostics": ["Html/ImgAlt", "Html/DuplicateId"],
"rubyTemplates.haml.disabledDiagnostics": ["Rails/MissingPartial"]
```

`rubyTemplates.slim.disabledDiagnostics` also applies to Skim templates, and `rubyTemplates.jbuilder.disabledDiagnostics` to Jbuilder and Builder views; `rubyTemplates.liquid.disabledDiagnostics` and `rubyTemplates.pug.disabledDiagnostics` turn off the Liquid and Pug ones. To silence a whole language, set `rubyTemplates.erb.diagnostics.enabled`, `rubyTemplates.haml.diagnostics.enabled`, `rubyTemplates.slim.diagnostics.enabled` or `rubyTemplates.pug.diagnostics.enabled` to `false` (in a `.ruby-templates.toml`: `diagnostics.enabled = false` under `[erb]`, `[haml]`, `[slim]` or `[pug]`). Thor templates (`*.tt`) get no diagnostics.

The [rules reference](/vscode-ruby-templates/reference/rules/) lists the formatter rules next to the ones that report these codes.
